# 五家报社 · 「广东海洋大学」每日监测方案

**监测媒体**：光明日报 / 南方日报 / 羊城晚报 / 中国教育报 / 湛江日报
**数据源**：各报社**官网数字报**（报纸电子版）—— 不是 Google/Bing News

---

## 一、结论：为什么不从 Google News 抓

你问得对。之前用 Google News 是图省事，实测下来它在这个场景**不能用**，三条硬证据：

**1. Google News 是标题级检索，正文提及全漏。**
2026-09-22 实测跑出的 4 条真报道，**标题里一个都没有"广东海洋大学"**：

| 命中文章（湛江日报） | 校名出现在哪 |
|---|---|
| 办通俗通晓通透的理论版 | 正文："汇聚…广东海洋大学、广东医科大学…6所高校马克思主义学院专家力量" |
| 汇聚专家智慧 激荡理论新声 | 正文："海洋经济、海洋种业…专题可以向广东海洋大学约稿" |
| 扎实抓好中央环保督察问题整改…红树林 | 正文："来自广东海洋大学、湛江湾实验室的专家提出意见建议" |
| 湛江市五一劳动奖状推荐对象公示 | 正文名单："刘建勇　广东海洋大学水产养殖系教师、教授" |

这 4 条 Google News **一条都抓不到**。报纸提到一所高校，绝大多数时候写在正文里，不是标题里。

**2. Google 对湛江日报收录早就停了。**
`site:gdzjdaily.com.cn` 在 Google News 里最新条目停在 2023 年，且混入大量无关内容（搜"广东海洋大学"返回的是《粤BA常规赛》《深圳梧桐山》）。而湛江日报恰恰是本次命中最多的报纸。

**3. 有延迟、有跳转。**
Google News 收录比报纸出版晚数小时到数天；返回的链接还是 `news.google.com/rss/articles/CBMi…` 跳转链，不是原文直链。

**官网数字报没有这些问题**：报纸上线即可抓、链接就是原文、全文匹配不漏正文。

## 二、方案原理

五家报社的数字报全部基于**方正系电子报系统**，结构高度统一，三段式：

```
第 1 版页  node_01.htm(l)   →  含当日全部版面链接（node_*）
单个版面页 node_*.htm(l)    →  含本版全部文章链接（content_*）
单篇文章页 content_*.htm(l) →  含标题 + 正文（正文在 <founder-content> 标签内）
```

所以流程是：**第 1 版 → 全部版面 → 全部文章 → 标题 + 正文全文匹配关键词**，
正文里提一句校名也能命中。

### 五家入口（第 1 版地址模板）

## 四、用法

```bash
cd /Users/quark/WorkBuddy/opencode/gdou-tracker

python3 daily_scan.py                  # 扫今天+昨天，只报「新增」命中（日常用这个）
python3 daily_scan.py --days 7         # 回溯最近 7 天
python3 daily_scan.py --kw 广东海洋大学 --kw 海大   # 多个关键词
python3 daily_scan.py --only 湛江日报,南方日报       # 只扫指定报社
python3 daily_scan.py --full           # 忽略增量记录，全量重报
python3 daily_scan.py --workers 8      # 并发数（默认 8）
python3 daily_scan.py --dry            # 只探测入口和版面，不抓文章
```

### 输出

| 路径 | 内容 |
|---|---|
| `hits/<时间戳>.md` | 每次运行的报告（各家扫描情况 + 新增命中 + 上下文） |
| `hits/index.html` | 历史全部命中汇总，可直接浏览 |
| `hits/archive.json` | 命中归档（结构化，便于二次加工） |
| `state/seen.json` | 增量状态（已判定过的文章 URL），保证只报新增 |

## 五、已知边界

- **数字报 = 纸质版内容**。报社官网的即时新闻频道（光明网、南方网等）更新更快、条数更多，但不等于报纸版面。如需把官网新闻频道也纳入监测，可在此脚本上追加一路采集。
- **当天报纸上线时间不固定**（一般在凌晨到上午）。脚本默认扫「今天 + 昨天」两天，所以即使当天还没上线也不会漏，第二天会自动补上。
- **图片版正文抓不到**。若报纸某版是整版图片排版（少见），文字提取会失败。当前五家实测均有文字版。
- **只匹配字面关键词**。默认按「广东海洋大学」精确匹配；如需覆盖简称、别称，用 `--kw` 多传几个。
- **对报社站点是轻量访问**：每天每站约 100~200 个请求、并发 8，属正常阅读量级。
