# 已废弃：基于 Google News 的旧方案

这里保留的是本项目的初版实现，**已被上级目录的 `daily_scan.py`（数字报直采）取代**。

## 为什么废弃（2026-09-22 实测）

Google News 是**标题级检索**，正文提及全漏。同日跑数字报全文扫描命中 4 条真报道，
**标题里一个都没有「广东海洋大学」**——校名全在正文里：

| 文章 | 校名出现在 |
|---|---|
| 办通俗通晓通透的理论版 | 正文："汇聚…广东海洋大学、广东医科大学…6 所高校马克思主义学院专家力量" |
| 汇聚专家智慧 激荡理论新声 | 正文："海洋经济、海洋种业…专题可以向广东海洋大学约稿" |
| 扎实抓好中央环保督察问题整改…红树林 | 正文："来自广东海洋大学、湛江湾实验室的专家提出意见建议" |
| 湛江市五一劳动奖状推荐对象公示 | 正文名单："刘建勇　广东海洋大学水产养殖系教师、教授" |

旧方案这 4 条**一条都抓不到**。另外 Google 对湛江日报的收录早在 2023 年就停了，
而湛江日报恰是命中最多的报纸。

## 文件

- `gdou_tracker.py` — 旧脚本：Google News 按站点 + 湛江站内搜索双通道
- `report.html` / `result.csv` / `result.json` — 旧脚本产出（182 条，其中高置信 11 条）

**仅作历史参考，不要再用。**
