# 已废弃：基于 Google News 的旧方案

这里保留的是本项目的初版实现，**已被上级目录的 `daily_scan.py`（数字报直采）取代**。

## 为什么废弃（实测）

Google News 是**标题级检索**，正文提及全漏。同日跑数字报全文扫描命中 4 条真报道，
**标题里一个都没有目标机构名**——机构名全在正文里：

| 报道类型 | 机构名出现在 |
|---|---|
| 理论版报道 | 正文："汇聚…示例大学、示例医科大学…6 所高校马克思主义学院专家力量" |
| 约稿报道 | 正文："海洋经济、海洋种业…专题可以向示例大学约稿" |
| 生态整改报道 | 正文："来自示例大学、示例实验室的专家提出意见建议" |
| 表彰公示 | 正文名单："示例大学水产养殖系教师、教授" |

旧方案这 4 条**一条都抓不到**。另外 Google 对湛江日报的收录早已停滞，
而湛江日报恰是命中最多的报纸。

## 文件

- `news_tracker.py` — 旧脚本：Google News 按站点 + 湛江站内搜索双通道

> 旧脚本产出（`report.html` / `result.csv` / `result.json`）已删除：它们是
> `news_tracker.py` 可随时重新生成的运行时结果，留在仓库里只会带来体积与陈旧数据。
> 需要时直接运行该脚本即可再生成。

**仅作历史参考，不要再用。**
